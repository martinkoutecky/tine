Built to sit beside Logseq — not replace it

Tine isn't a fork or a clone trying to pull you away. It's an independent reimplementation that deliberately targets Logseq's on-disk format, so your notes stay plain Markdown files you fully own.

What Tine adds on top

These started as "I wish Logseq did this." You get them without giving up a single feature of your file format.

Split view and tabs

Split the window into panes, each with its own tabs and history. Alt+click opens a link beside what you're reading; Ctrl+click or middle-click opens it in a background tab. Pin and drag tabs, move them between panes, and navigate panes from the keyboard. The layout survives a restart.

Search that becomes a query

Open every Ctrl+K result in a persistent tab, refine it with friendly filters, and view the same matches as a list, table, or board. The visual query editor and the query text stay in sync — edit either one — and an empty result can tell you why it's empty. Name it when it deserves to become a query page.

Sheets

Turn any bullet and its children into a spreadsheet-style grid, a typed field table, or a board — with formula columns, filters, aggregates, group-by, and CSV/TSV import. It's all still plain Logseq Markdown; the views are harmless tine.* properties Logseq quietly ignores.

Concord: calm conflicts, whatever you sync with

When Syncthing, Dropbox or git leaves two versions of a page, Tine shows them side by side block by block, pre-selects a suggestion from the last version both sides agreed on, and lets you keep either, both, or a merge. A big git checkout or sync burst is handled as one calm update, not a storm of reloads.

Live export: publish a graph that still feels like Tine

Export pages as a static site that keeps search, tabs, split view and navigation working — no server needed. The Guide is exactly that. From the app, or tine export live ~/notes from the command line; your publication settings decide which pages go out.

Global quick-capture

Bind a desktop hotkey and a small always-on-top box pops up from any app — with the full editor — and files a bullet to today's journal, or to a new page. Even when Tine isn't focused.

And a lot of smaller things

Better defaults — always one click back to Logseq. Anything Tine does differently is badged Differs from Logseq in Settings, with a ↩ Match Logseq button.
  • Copy only the selected blocks — selecting just a parent no longer copies its whole subtree. (Logseq copies the subtree — one click to restore.)
  • Strip collapsed:: on copy so a paste into a text editor is clean. (Toggle off to match Logseq.)
  • Click a block reference to scroll to it in place, or switch back to Logseq's zoom-in behavior.
  • Link-autocomplete default — create a new page (like Logseq) or link the first match.
  • Fully remappable keyboard shortcuts — in Settings or via config.edn :shortcuts.
  • Journal date format, file-format, and watcher mode — all read from your config.edn and adjustable in-app.

Safe with your notes, open about how it's made

Careful with your files

  • Native speed without risk — a pure-Rust core and a tiny native runtime, no Electron; typing never waits on disk.
  • Conflicts are detected, never silently overwritten — and reviewed block by block with Concord.
  • Launch snapshots with one-click restore, delete-to-trash, and transactional renames.
  • No lock-in — it round-trips byte-for-byte with Logseq, so you can walk away at any time and lose nothing.

Built by AI, in the open

Tine is vibe-coded — built by Claude Code, with help from Codex, under human direction and review. We're not hiding that, and we're not making a thing of it either; it's simply how Tine is made.

AI-built software makes some people wary — fair enough. So Tine is made to be checked, not taken on faith: every line is open source (AGPL-3.0), and it only ever touches plain Markdown you already own. Point it at a copy of your graph and judge it by how it behaves.
