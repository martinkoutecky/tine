# واژه‌نامهٔ ترجمهٔ فارسی

Translator notes; this file is not loaded. Machine-written first draft (tine#823), feedback from the
reporter welcome. Graph content, markers (`TODO`, `DOING`), query syntax, file names, keys and code stay in
the original. Keep Fluent variables, references and selectors. Persian punctuation (، ؛ ؟), ZWNJ in plurals
(`صفحه‌ها`), Tine and Logseq in Latin. Numbers go through `NUMBER`, which gives Persian digits in `fa`; digits in
prose are Persian too, except in code, sizes copied from a file name, and keyboard shortcuts.
