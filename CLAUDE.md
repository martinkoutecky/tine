# Tine — Claude project instructions (pointer)

The shared agent working agreement (used by both Codex and Claude Code) lives
outside this repo at `../tine-agents/AGENTS.md`, kept there so a
`git clean` in the worktree can't delete it. Read it before working; put project
flows there, not here. The default is the sibling `tine-agents` directory
(relative to this file). For a different location, set `TINE_AGENTS` and read
`$TINE_AGENTS/AGENTS.md` explicitly; see `AGENTS.md` for the missing-file fallback.
