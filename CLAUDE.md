work without the maintainer's private agreement: if `../tine-agents/AGENTS.md`
is missing, carry on with the public material listed there.

outside this repo at `../tine-agents/AGENTS.md`, kept there so a `git clean` in
the worktree can't delete it. When present, put project flows there, not here.
